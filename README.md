# Табель

Android-застосунок, який читає робочий табель із Google-таблиці й показує,
хто з тобою на зміні цього дня, а також рахує зарплату за місяць.

Зроблено під конкретний графік: доба через дві (24 години), решта колективу —
плаваючий графік по 8 годин та зміни по 11 годин.

## Що вміє

**Зміна** — на обрану дату показує твій статус (доба / вихідний / відпустка)
і всіх, хто працює того ж дня, згрупованих за типом зміни. Для доби окремо
показує, хто здає тобі зміну і хто приймає її наступного ранку.

**Місяць** — календар твого графіка з позначками та підсумком:
кількість діб, годин, днів відпустки й лікарняного.

**Зарплата** — розрахунок за місяць із розбивкою та поясненням формули.

## Як рахується зарплата

```
надбавка = НАДБАВКА × (відпрацьовані доби / планові доби місяця)
на руки  = СТАВКА + надбавка
```

Ставка нараховується за повний місяць і не залежить від відпустки.
Надбавка — за роботу «доба через дві» замість норми «доба через три».
Вона ділиться пропорційно: якщо частину діб за тебе відпрацював інший,
його частка йде йому. Застосунок знаходить таку заміну в табелі й показує
поіменно, хто саме і в які дні тебе закривав.

Планова кількість діб виводиться з самого табеля — з кроку ротації та
першої доби місяця, — а не задана числом. Тому в місяцях, де діб 11 або 9,
розрахунок лишається правильним.

Розрахунок орієнтовний: податки, премії та відпускні не враховані.

## Як читається таблиця

Таблиця відкривається лише на перегляд, тож застосунок працює як звичайний
читач без авторизації:

1. Зі сторінки `/htmlview` береться перелік аркушів — пари «назва → gid».
   Це потрібно, бо назви аркушів у таблиці записані неоднаково:
   `серпень 2026`, `Листопад 2024`, `травень 2024 ` з пробілом у кінці,
   `грудень2022` без пробілу. Зіставлення йде за нормалізованою назвою.
2. Потрібний місяць завантажується як CSV через `/export?format=csv&gid=…`.
3. CSV розбирається: аркуш складається з кількох блоків, кожен починається
   рядком-шапкою з числами місяця 1..31; під шапкою — рядки людей.

Позиції рядків «пливуть» від місяця до місяця, бо люди приходять і йдуть,
тому нічого не прив'язано до номерів рядків — пошук іде за прізвищем
у колонці «Прізвище».

Завантажений місяць кешується у внутрішній пам'яті, тож графік лишається
доступним без інтернету.

### Позначки в табелі

| Позначка | Значення |
|---|---|
| `24` | доба |
| `11` | зміна 11 годин |
| `8` | денна зміна |
| `В` | вихідний |
| `о/п` | відпустка |
| `б/л` | лікарняний |
| `НА` | відпустка без збереження зарплати |
| `Н` | відсутній |

## Налаштування

Прізвище в табелі, ставка, надбавка, час початку доби та денної зміни,
ID Google-таблиці й тема (системна / світла / темна).

## Збірка

```bash
./gradlew :app:assembleDebug
```

Тести — парсер табеля, перелік аркушів і розрахунок зарплати на реальних
даних із таблиці:

```bash
./gradlew :app:testDebugUnitTest
```

### Підписана релізна збірка

Потрібен keystore і файл `keystore.properties` поруч із ним (обидва не
потрапляють у репозиторій — див. `keystore.properties.example`):

```bash
./gradlew :app:assembleRelease
```

## Обмеження

Час змін у застосунку — це налаштування, а не дані з таблиці. У легенді
табеля є три варіанти (8:00–17:00, 9:00–18:00, 11:00–20:00), але вони
закодовані кольором заливки клітинки з прізвищем, а CSV-експорт кольори
не передає. Тому показується один час за замовчуванням, який можна змінити
в налаштуваннях.

Якщо власник таблиці закриє доступ за посиланням, застосунок працюватиме
лише на збереженій копії.
