# Табель

Android-застосунок, який читає робочий табель із Google-таблиці й показує,
хто з тобою на зміні цього дня, а також рахує зарплату за місяць.

Зроблено під конкретний графік: доба через дві (24 години), решта колективу —
плаваючий графік по 8 годин та зміни по 11 годин.

## Що вміє

**Зміна** — на обрану дату показує твій статус (доба / вихідний / відпустка)
і всіх, хто працює того ж дня, згрупованих за типом зміни. Відсутні теж
у списку, але позначені червоним — видно, кого сьогодні немає і чому.
Для доби окремо показує, хто здає тобі зміну і хто приймає її наступного ранку.

**Місяць** — календар твого графіка з позначками та підсумком:
кількість діб, годин, днів відпустки й лікарняного.

**Люди** — список колективу з гортанням по місяцях. Тап по людині відкриває
її графік, дні, коли ваші зміни збігаються, і поле для індивідуального часу
початку зміни. Для місяців, яких ще немає в таблиці, показується склад
за попередній місяць і прогноз діб за ротацією.

**Підсумки** — за рік або за весь час: скільки годин, днів і діб відпрацьовано,
скільки вихідних у кого, з ким найчастіше збігаються зміни, скільки вихідних
випало на суботу-неділю та найдовша перерва поспіль.

**Зарплата** — розрахунок за місяць із розбивкою, поясненням формули та
історією за 12 місяців. Для кожного місяця можна вписати, скільки прийшло
насправді, і бачити розбіжність із розрахунком.

**Сповіщення** — нагадування в день зміни та повідомлення, коли твої доби
в табелі зрушили.

**Віджет** — статус на сьогодні й дата наступної доби просто на екрані.

Дні й місяці гортаються жестом вліво-вправо, не тільки стрілками.

## Як рахується зарплата

```
надбавка = НАДБАВКА × (відпрацьовані доби / планові доби місяця)
на руки  = СТАВКА + надбавка
```

Ставка нараховується за повний місяць і не залежить від відпустки.
Надбавка — за роботу «доба через дві» замість норми «доба через три».
Вона ділиться пропорційно: якщо частину діб за тебе відпрацював інший,
його частка йде йому. Застосунок знаходить таку заміну в табелі й показує
поіменно, хто саме і в які дні тебе закривав.

Планова кількість діб виводиться з самого табеля — з кроку ротації та
першої доби місяця, — а не задана числом. Тому в місяцях, де діб 11 або 9,
розрахунок лишається правильним.

Розрахунок орієнтовний: податки, премії та відпускні не враховані.

## Як читається таблиця

Таблиця відкривається лише на перегляд, тож застосунок працює як звичайний
читач без авторизації:

1. Зі сторінки `/htmlview` береться перелік аркушів — пари «назва → gid».
   Це потрібно, бо назви аркушів у таблиці записані неоднаково:
   `серпень 2026`, `Листопад 2024`, `травень 2024 ` з пробілом у кінці,
   `грудень2022` без пробілу. Зіставлення йде за нормалізованою назвою.
2. Потрібний місяць завантажується як CSV через `/export?format=csv&gid=…`.
3. CSV розбирається: аркуш складається з кількох блоків, кожен починається
   рядком-шапкою з числами місяця 1..31; під шапкою — рядки людей.

Позиції рядків «пливуть» від місяця до місяця, бо люди приходять і йдуть,
тому нічого не прив'язано до номерів рядків — пошук іде за прізвищем
у колонці «Прізвище».

Завантажений місяць кешується у внутрішній пам'яті, тож графік лишається
доступним без інтернету.

### Позначки в табелі

| Позначка | Значення |
|---|---|
| `24` | доба |
| `11` | зміна 11 годин |
| `8` | денна зміна |
| `В` | вихідний |
| `о/п` | відпустка |
| `б/л` | лікарняний |
| `НА` | відпустка без збереження зарплати |
| `Н` | відсутній |
| порожньо | залежить від людини — див. нижче |

**Порожня клітинка означає протилежне залежно від того, чий це рядок.**

У чергових (добова ротація) вихідні не позначають літерою `В` — вільні дні
між добами просто лишаються порожніми. Для них порожньо = вихідний.

У решти навпаки: вихідні проставлені літерою `В` наперед, а години `8` і `11`
табельник записує день у день, за фактом. Тому порожня клітинка в їхньому
рядку — це робочий день за графіком, якому ще не записали фактичний прихід.
Застосунок показує таких людей окремою секцією «Мають працювати» й підказує
звичну для них тривалість дня, взяту з уже заповнених клітинок.

Розрізняє їх ознака «чи є в людини доби цього місяця» — саме вона визначає,
у який бік читати порожню клітинку.

Години в табелі — фактично відпрацьовані, без обіду. На зміні людина на
годину довше: `8` — це з 9:00 до 18:00, `11` — з 9:00 до 21:00.

## Налаштування

Прізвище в табелі, ставка, надбавка, час початку доби та денної зміни,
ID Google-таблиці й тема (системна / світла / темна).

## Збірка

```bash
./gradlew :app:assembleDebug
```

Тести — парсер табеля, перелік аркушів і розрахунок зарплати на реальних
даних із таблиці:

```bash
./gradlew :app:testDebugUnitTest
```

### Підписана релізна збірка

Потрібен keystore і файл `keystore.properties` поруч із ним (обидва не
потрапляють у репозиторій — див. `keystore.properties.example`):

```bash
./gradlew :app:assembleRelease
```

## Обмеження

**Часу початку зміни в таблиці немає взагалі.** Легенда з варіантами
8:00–17:00, 9:00–18:00 та 11:00–20:00 не має кольорових плашок — усі клітинки
в рядках 43–47 білі. Кольори прізвищ теж не про час: в одній кольоровій групі
опиняються і 8-годинні, і 11-годинні, а 8-годинні розкидані по шести кольорах
при трьох варіантах часу. Тому початок зміни задається вручну: загальний
за замовчуванням у налаштуваннях і окремий для конкретних людей на їхніх
картках. Тривалість береться з табеля.

**Майбутні дні видно тільки для чергових** — решту табельник заповнює
за фактом. Для місяців, яких ще немає в таблиці, застосунок рахує доби
з ротації й прямо позначає їх як прогноз.

Якщо власник таблиці закриє доступ за посиланням, застосунок працюватиме
лише на збереженій копії.
